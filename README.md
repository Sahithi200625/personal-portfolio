# 🌐 Personal Portfolio

A modern and responsive **Personal Portfolio Website** created to showcase my skills, projects, education, certifications, and contact information.

## 🚀 Features

* 🏠 Home section
* 👩‍💻 About Me section
* 🛠️ Skills section
* 📚 Education details
* 💻 Projects showcase
* 📜 Certifications
* 📧 Contact section
* 📱 Responsive design for different screen sizes
* 🎨 Clean and user-friendly interface

## 🛠️ Technologies Used

* **HTML5** – Website structure
* **CSS3** – Styling and responsive design
* **JavaScript** – Interactive functionality

## 📂 Project Structure

```text
Personal-Portfolio/
│
├── index.html
├── style.css
├── script.js
└── assets/
    └── images/
```

## ▶️ How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Explore the portfolio website.

## 🎯 Purpose

The main purpose of this portfolio is to present my **academic background, technical skills, projects, and achievements** in one place and to showcase my work to recruiters and potential employers.
